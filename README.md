# فرشبازار (FarshBazaar) — نسخهٔ نمایشی v1

پلتفرم تخصصی فرش دستباف و ماشینی ایران و جهان، با تأکید بر اصالت، آموزش خریدار، و اصل بنیادین «ما فرش را با چشم و دست می‌شناسیم، نه با عکس».

## 🛠️ دستورات کامپایل و ساخت (Build)

برای کامپایل و اجرای تست‌ها در محیط محلی:

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

یا در ترمینال محیط ساخت:

```bash
gradle assembleDebug
gradle :app:testDebugUnitTest
```

## 📋 چک‌لیست آزمون دستی (Manual QA)

۱. **ورود از Splash:** پس از لود ۲ ثانیه‌ای و مشاهده اصل مادر، به صفحه اصلی هدایت شوید.
۲. **فیلتر دسته‌بندی‌ها:** بر روی چیپ‌های «فرش دستباف»، «فرش ماشینی» و «خدمات» کلیک کنید و فیلتر شدن آنی لیست را مشاهده کنید؛ روی «صنایع‌دستی» کلیک کنید تا پیام «به‌زودی» ظاهر شود.
۳. **بررسی چک‌لیست ۱۶ شاخص:** وارد جزئیات یک قالی شوید، چک‌باکس‌های ریشه، تقارن و رج را تیک بزنید؛ وضعیت تیک‌ها در دیتابیس Room ذخیره می‌شود.
۴. **لایک و نظر:** دکمه قلب بالای صفحه را بزنید؛ شمارنده لایک افزایش یافته و در پروفایل به امتیاز XP اضافه می‌شود.
۵. **غرفه فروشنده و فالو:** از صفحه جزئیات روی نام فروشنده کلیک کرده و دکمه «دنبال کردن» را آزمایش کنید.
۶. **جستجو:** نام مکتبی مثل «تبریز» یا «اصفهان» را در کادر جستجو تایپ کنید.
۷. **اصول ۱۴گانه:** از منوی بالای صفحه وارد اصول شوید و ۱۴ اصل اخلاقی فرشبازار را مطالعه کنید.
۸. **آموزش شاخص‌ها:** کارت‌های ۱۶گانه را لمس کنید تا توضیحات تخصصی باز و بسته شوند.
